## Dataset numérico

O dataset numérico foi gerado pelo script
`scripts/gerar_dataset_numerico.py`. Ele é sintético e não utiliza dados de
pacientes reais. As variáveis foram escolhidas por sua relação com a avaliação
de risco cardiovascular, apenas para fins de estudo.
