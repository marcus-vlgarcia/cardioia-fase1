# ECGs derivados do MIT-BIH

Esta pasta contém 100 PNGs gerados de segmentos reais da MIT-BIH Arrhythmia Database, PhysioNet, versão 1.0.0, DOI `10.13026/C2F305`, licença Open Data Commons Attribution 1.0.

- `train/`: registros 100–106, 70 imagens;
- `validation/`: registros 107–108, 20 imagens;
- `test/`: registro 109, 10 imagens.

A separação é feita por registro/paciente. Cada imagem representa 10 segundos e dois canais. Consulte o manifesto para proveniência e hash. São visualizações derivadas, não exames diagnósticos independentes e não possuem rótulo clínico por segmento.
