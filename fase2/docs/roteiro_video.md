# Demonstração — 3 minutos

O vídeo legendado mostra dados, lógica e resultados obtidos na execução do
projeto. É uma apresentação dos resultados executados, não uma gravação de
atendimento ou uso clínico. Pode ser usado diretamente ou como roteiro para
uma gravação de tela com voz do grupo.

| Tempo | Conteúdo |
| --- | --- |
| 00:00–00:20 | Identificação do grupo, objetivo e caráter simulado |
| 00:20–00:40 | Relato completo com início, sintomas e impacto |
| 00:40–01:00 | Mapa, normalização, dois sintomas e negação |
| 01:00–01:20 | Resultado real do extrator e arquivo de saída |
| 01:20–01:40 | 80 frases, rótulos e divisão por cenário |
| 01:40–02:00 | TF-IDF e treinamento com Regressão Logística |
| 02:00–02:20 | Acurácia, baseline e matriz de confusão |
| 02:20–02:40 | Falso negativo, negações e vieses |
| 02:40–03:00 | Reprodutibilidade, arquivos e conclusão |

## Publicação

Enviar o MP4 ao YouTube, selecionar visibilidade **não listado** e copiar o
link real para a seção de vídeo do README principal e do README da Fase 2.
Conferir acesso pelo link sem entrar na conta. Não é necessário publicar o vídeo
como público. O limite do enunciado é de quatro minutos.
